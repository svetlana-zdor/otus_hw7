# Сравнение ответов модели qwen2.5 при генерации тест-кейсов

Данный проект содержит скрипт для автоматической генерации тест-кейсов с использованием локальной языковой модели `qwen2.5` (через Ollama) на основе трех разных промптов, а также оценивает качество ответов по критериям: **полнота**, **формат**, **точность**.

## Структура репозитория
- `prompts.txt` — файл, содержащий три варианта промптов с разной степенью детализации.
- `script.py` — Python-скрипт для отправки промптов в Ollama, автоматической оценки ответов и записи результатов.
- `compare_answers_resuls.txt` — файл с результатами сравнения ответов LLM.

## Требования для запуска
1. Установленный Python (версии 3.8 и выше).
2. Установленная [Ollama](https://ollama.com/) с загруженной моделью `qwen2.5`.
3. Установленная библиотека Python для работы с Ollama:
   ```bash
   pip install ollama
